# Mirrors mascot

`playground.html` is the mascot playground (published as a Claude artifact). Open it in a browser to try the mascot on a
video and a comic JSON. `settings.json` holds the slider values Sarah chose on 7 Nov 2026; they are also the playground's
defaults. When the mascot moves into Remotion (a "Mascot" style next to the bubbles), it starts from these two files.
